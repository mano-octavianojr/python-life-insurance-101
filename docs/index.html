Ready to try the code?

Click an Open in Colab badge to run a lesson in your browser. Sign in to Google if prompted and save a copy in Drive to keep your changes. Lesson 08 loads the public sample CSV automatically when local data is absent. You can also run the notebooks in JupyterLab on your computer with Python 3.10 or newer. Download the repository to keep notebooks and sample data together.

  1. Clone or download the GitHub repository.
  2. Open a terminal in the project folder and run the commands below.
  3. In JupyterLab, open notebooks/01_first_program.ipynb. Press Shift+Enter to run a cell.
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyter lab

Windows activation: .venv\Scripts\activate. Try the student workspace before revealing the solution. Restart the kernel and run all cells to reset a lesson.
