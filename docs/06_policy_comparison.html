06. The Policy Comparison Club¶

Suggested time: 45–60 minutes. Work through lessons in order; each notebook includes its own runnable examples.

All people, policies, prices, and records are fictional. Amounts use Philippine pesos (₱ / PHP). This is a coding lesson, not financial advice. Real coverage and claims depend on policy terms and applicable law. Never enter personal financial or health information.

Run this lesson in your browser with Google Colab. Sign in to Google if prompted. Use File → Save a copy in Drive to keep your work, then run the cells in order.

Story opening¶

The school club asks Maya and Leo to present three fictional term policies. Their task is to show which fit a sample budget, not choose a policy for anyone.

Learning goals¶

Loop over a list of dictionaries; filter records.

Insurance in everyday words¶

The coverage amount is the benefit specified for a covered death. A premium is the payment, not the coverage amount. Policies can also differ in exclusions, payment rules, eligibility, and renewal terms; this small table omits those details.

Python toolbox¶

Each list item is a policy dictionary. Read fields by key. An if statement inside a loop can select matching records. .append() adds an item to a list.

Predict, then run¶

Which policies fit a monthly budget of ₱400?

policies = [
    {"name": "Oak", "monthly": 250, "coverage": 300000, "term": 10},
    {"name": "River", "monthly": 350, "coverage": 500000, "term": 10},
    {"name": "Sky", "monthly": 600, "coverage": 800000, "term": 20},
]
budget = 400
matches = []
for policy in policies:
    print(f"{policy['name']}: ₱{policy['monthly']}/month, ₱{policy['coverage']:,} benefit, {policy['term']} years")
    if policy["monthly"] <= budget:
        matches.append(policy["name"])
print("Within this budget:", matches)
