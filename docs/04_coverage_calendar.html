04. Coverage Has a Calendar¶

Suggested time: 45–60 minutes. Work through lessons in order; each notebook includes its own runnable examples.

All people, policies, prices, and records are fictional. Amounts use Philippine pesos (₱ / PHP). This is a coding lesson, not financial advice. Real coverage and claims depend on policy terms and applicable law. Never enter personal financial or health information.

Story opening¶

Leo finds a fictional policy with a start date and an end date. Maya checks three dates to understand the coverage window before discussing any claim.

Learning goals¶

Compare dates; use booleans and if/elif/else.

Insurance in everyday words¶

Term life insurance covers a set period. It generally does not pay a death benefit if the insured person survives beyond that term. For this example only, the start date is included and the end date is excluded. Actual effective times, renewal, exclusions, and continued coverage depend on policy terms.

Python toolbox¶

date(year, month, day) creates a calendar date. < means earlier than and >= means on or after. Comparisons give True or False. Indent the instructions inside each conditional branch by four spaces.

Predict, then run¶

Is the exact end date inside our stated window?

from datetime import date
start = date(2026, 1, 1)
end = date(2036, 1, 1)
event_date = date(2030, 6, 15)
if event_date < start:
    status = "Before the example window"
elif event_date >= end:
    status = "After or at the end of the example window"
else:
    status = "Inside the example window; this is not a claim decision"
print(status)
